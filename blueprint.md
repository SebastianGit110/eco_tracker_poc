
# Mini Calculator App

## Overview

This project is a simple and elegant mini-calculator application built with Flutter. It provides basic arithmetic operations in a clean and user-friendly interface.

## Features

*   **Modern Design:** A visually appealing interface with a balanced layout, custom fonts, and a vibrant color scheme.
*   **Basic Operations:** Supports addition, subtraction, multiplication, and division.
*   **Responsive UI:** Adapts to different screen sizes, ensuring a seamless experience on both mobile and web.
*   **Interactive Elements:** Buttons with a "glow" effect and clear visual feedback.
*   **Light/Dark Mode:** Includes a theme toggle for user preference.

## Current Plan

*   **Dependencies:** Add `provider` for state management and `google_fonts` for custom typography.
*   **Theming:** Implement a comprehensive theme with Material 3, a custom color scheme, and text styles.
*   **UI Scaffolding:** Create the main calculator layout with a display screen and button grid.
*   **State Management:** Use a `ChangeNotifier` to manage the calculator's state (input, result, etc.).
*   **Button Implementation:** Create reusable button widgets for numbers, operators, and actions (e.g., clear, equals).
*   **Logic:** Implement the core calculation logic to handle user input and compute results.
